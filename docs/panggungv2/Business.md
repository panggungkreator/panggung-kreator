## 1. Model Bisnis Overview

Panggung Kreator beroperasi sebagai **komunitas self-development berbasis EdTech** dengan model bisnis berlapis — menggabungkan revenue dari program berbayar, layanan B2B, dan ekosistem afiliasi.

**Filosofi:** *Komunitas dulu, monetisasi ikut.*  
Funnel dimulai dari engagement gratis → konversi ke program berbayar.

---

## 2. Revenue Streams

### 2.1 Membership Akademi

Program inti berbayar dengan akses ke full mentoring + kursus online.

| Paket | Harga | Target Segmen | Benefit Utama |
|---|---|---|---|
| **Regular** | Rp49.000 | Member baru yang siap serius | Sesi Panggung, Level Up Session, Resource |
| **MVP** | TBD | Member aktif yang mau diprioritaskan | Semua Regular + prioritas slot mentoring |
| **Private Mentoring** | TBD | Individu yang ingin 1-on-1 intensif | Sesi privat dengan mentor |

> **Catatan:** Sistem paket bersifat **Lifetime** — tidak ada durasi/expiry.

### 2.2 Afiliasi (Komisi 60:40)

Program afiliasi untuk mendorong member aktif & komunitas lain merekomendasikan program.

| Parameter | Detail |
|---|---|
| Model | Komisi per konversi (referral sukses bayar) |
| Bagi Hasil | 60% untuk afiliator, 40% untuk Panggung Kreator |
| Mekanisme | Kode referral unik per afiliator, diinput saat checkout |
| Afiliator Potensial | Alumni, member aktif, komunitas partner |

### 2.3 Bootcamp / Inhouse Training

Program intensif berbentuk paket B2B atau event berbayar.

| Format | Target Klien | Keterangan |
|---|---|---|
| **Bootcamp** | Individual (umum) | Program inkubasi beberapa hari, mentor pakar |
| **Inhouse Training** | Perusahaan, kampus, institusi | Pelatihan public speaking / content creation custom |
| **Workshop** | Umum, side community BTB | Event berbayar, materi spesifik satu sesi |

### 2.4 Live Host Streaming

Layanan penyediaan host/MC untuk live streaming platform (TikTok, Instagram, Shopee Live, dll).

| Item | Detail |
|---|---|
| Model | Talent supply dari member/alumni terlatih |
| Revenue | Fee per sesi atau retainer |
| Pipeline | Member Priority → dilatih → jadi live host |

### 2.5 Agensi (Talent & Content)

Panggung Kreator sebagai **agensi talent** untuk menyalurkan member ke proyek eksternal.

| Layanan | Keterangan |
|---|---|
| **Booking MC / Speaker** | Penyediaan MC untuk event klien |
| **Content Creator** | Penyediaan kreator konten untuk brand |
| **Personal Branding Konsultasi** | Layanan konsultasi branding personal |

## 3. Community Funnel & Konversi

```
AWARENESS
  Medsos (IG, Threads, TikTok) → Konten Daily / Tips / Entertainment
  Rekomendasi teman / alumni
        ↓
ACQUISITION
  Landing Page Web Komunitas (panggungkreator.web.id)
  Daftar Member Gratis → Masuk WA Group BTB atau General
        ↓
ACTIVATION
  Hadir di Open Mic, Sharing Session, Networking
  Admin rekam kehadiran → Riwayat tercatat di My Profile
        ↓
CONVERSION
  CTA Upgrade muncul di /myprofile
  Landing Page Akademi (akademi.panggungkreator.web.id)
  Checkout Rp49.000 → Dashboard + Full Mentoring + Kursus
        ↓
RETENTION
  Mentoring 1x/minggu, resource berkala, community engagement
        ↓
REFERRAL
  Alumni jadi afiliator, live host, mentor → pendapatan aktif
```
