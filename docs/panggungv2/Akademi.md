## 1. Gambaran Umum Akademi

Akademi Panggung Kreator adalah **learning hub** resmi komunitas yang menyediakan:

- **Full Mentoring** — sesi bimbingan terstruktur 1x/minggu
- **Kursus Online Lifetime** — akses seumur hidup ke materi digital
- **Bahan Mentoring** — resource yang dikemas dari hasil diskursus tim
- **Sesi Panggung** — praktik langsung di depan audiens
- **Level Up Session** — sesi naik level terstruktur

**Filosofi Akademi:** Transformasi nyata, bukan sekadar kelas.

## 6. Mentoring System

### 6.1 Mekanisme Mentoring

| Aspek | Detail |
|---|---|
| **Frekuensi** | 1x per minggu |
| **Format** | 1-on-1 (Private) atau kelompok kecil (Regular/MVP) |
| **Booking** | Via halaman `/dashboard/jadwal` |
| **Bahan** | Disiapkan mentor dari "Bahan Mentoring" yang sudah dikurasi |
| **Rekap** | Admin mencatat progres per member di Admin CMS |

### 6.2 Alur Sesi Mentoring

```
Member login ke Dashboard
  ↓ Buka /dashboard/jadwal
  ↓ Pilih slot mentoring tersedia
  ↓ Konfirmasi booking
Notifikasi ke member & mentor
  ↓ Sesi berlangsung (online / offline)
  ↓ Mentor mencatat progress di Admin CMS
Member melihat rekap progress di dashboard
```

## 7. Analisis Database Kehadiran & Mentoring

> **PIC:** Bagas (Koordinator)

### 7.1 Data yang Perlu Dianalisis

| Data | Sumber | Tujuan Analisis |
|---|---|---|
| **Kehadiran Event** | Tabel `attendances` + `events` | Frekuensi kehadiran per member, event paling diminati |
| **Progres Mentoring** | Tabel `mentoring_sessions` | Member dengan progres terbaik, drop-off analysis |
| **Konversi Tier** | Tabel `members` (kolom `membership_tier`) | Waktu rata-rata free → berbayar |
| **Engagement Program** | Cross-tabel attendance + packages | Program mana yang paling drive konversi |

### 7.2 Output yang Diharapkan dari Analisis

1. **Laporan Kehadiran Bulanan** — siapa yang hadir, berapa kali, acara apa
2. **Analisis Konversi** — funnel dari gratis ke berbayar, bottleneck di mana
3. **Rekomendasi Program** — berdasarkan data, program apa yang perlu diperkuat atau dipangkas
4. **Insight untuk Brainstorming** — bahan diskusi tim untuk pengembangan kurikulum
