## 🚀 Fase 1: Quick Wins & Basis Operasional (Prioritas Tinggi)

### 1. Seeding & Data Entry Event [DONE]

- **Target:** Tabel `public.events` di Supabase.
- **Eksekusi Teknis:**
  - Insert record event mendatang langsung via Supabase Table Editor atau SQL console.
  - Kolom utama: `title`, `description`, `event_date`, `start_time`, `end_time`, `location_name`, `location_url`, `event_type` (`online` | `offline` | `mentoring`), `banner_url`.
  - Verifikasi data tampil pada rute `/absensi/[eventId]` dan tab *Absensi* di `/myprofile`.

### 2. Implementasi Admin Dashboard (`/admin/page.tsx`) [DONE]

- **Target:** Mengganti placeholder statis di `front/app/(admin)/admin/page.tsx`.
- **Desain UI:**
  - **4 Stat Cards (Grid):** Total Member (`members.count()`), Total Omset (`transactions.sum(amount)`), Event Aktif (`events.gt('event_date', now)`), dan Pembayaran Pending (`payment_confirmations.eq('status', 'pending')`).
  - **Widget Tabel "Transaksi Terbaru":** List 5 transaksi terakhir dari tabel `transactions` join `members`.
- **Eksekusi Teknis:**
  - Lakukan agregasi data *server-side* secara paralel via `Promise.all()` menggunakan `createClient()` Supabase.
  - Buat komponen `MetricCard` reusable berbasis Tailwind CSS di `front/app/(admin)/admin/components/`.

### 3. Modul Role Management Admin (`/admin/admins`)

- **Target:** Integrasi antarmuka pengangkatan member ke tabel `public.admin_roles` dan `public.members`.
- **Desain UI:**
  - Tombol trigger dialog `AddAdminFromMemberDialog` pada header `/admin/admins`.
  - Input form: Autocomplete pencarian member (`role = 'member'`), input `label` (cth: "Super Admin", "Finance"), dan color picker label.
- **Eksekusi Teknis:**
  - Implementasi Server Action `promoteMemberToAdminAction({ memberId, label, color })`.
  - Jalankan transaksi atomik via `createServiceRoleClient()`: Update `members.role = 'admin'` dan `INSERT INTO admin_roles (member_id, label, color, status) VALUES (...)`.
  - Validasi proteksi akses pada `front/middleware.ts` dan navigasi sidebar `AdminLayout.tsx`.

## ⚙️ Fase 2: Integrasi Pembayaran Otomatis (Prioritas Menengah)

### 4. Integrasi Payment Gateway Mayar.id

- **Target:** Endpoint `/api/webhooks/mayar/route.ts` dan Server Action `checkout-actions.ts`.
- **Alur & Eksekusi Teknis:**
  - **Checkout Flow:** Ganti flow upload bukti transfer manual dengan HTTP request ke Mayar API `POST https://api.mayar.id/hl/v1/payment/create` (payload: `amount`, `customer_name`, `customer_email`, `redirect_url`).
  - **Webhook Listener:** Buat Route Handler `front/app/api/webhooks/mayar/route.ts` untuk memproses payload status `payment.received`.
  - **Auto-Fulfillment:** Panggil fungsi internal `confirmPaymentWithRewardAction(transactionId)` saat webhook terverifikasi:
    - Update `transactions.status = 'success'`.
    - Buat akses paket/membership pada tabel `member_packages`.
    - Hitung dan distribusikan saldo afiliasi ke `members.commission_balance` serta catat mutasi di `affiliate_ledgers`.

## 🧠 Fase 3: Fitur Baru & Ekspansi Platform (Prioritas Lanjutan)

### 5. Modul Kolaborasi / Collab (`/admin/collab`)

- **Target:** Skema database baru `public.collabs` (mengadopsi arsitektur `venues` & `partners`).
- **Struktur Data:**
  - Tabel `collabs`: `id (uuid, PK)`, `partner_name (text)`, `category (text)`, `pic_name (text)`, `pic_contact (text)`, `agreement_doc_url (text)`, `revenue_share_pct (numeric)`, `status (enum: draft, active, ended)`, `created_at (timestamptz)`.
- **Desain UI & Eksekusi Teknis:**
  - Buat folder rute `front/app/(admin)/admin/collab/` (`page.tsx` + `CollabClient.tsx`).
  - Implementasi Data Table dengan filter `status` & pencarian nama mitra.
  - Implementasi Modal Form CRUD (React Hook Form + Zod) dengan storage bucket Supabase untuk upload dokumen MoU/perjanjian.

### 6. Mobile App Admin Monitoring

- **Target:** Aplikasi *mobile* terpisah (React Native / Expo).
- **Arsitektur Teknis:**
  - **Auth:** Supabase Auth SDK (`@supabase/supabase-js`) dengan verifikasi `role === 'admin'`.
  - **Monitoring Dashboard Screen:** Fetching 4 metrik stat card utama secara realtime.
  - **Realtime Listener & Notifications:** Integrasi Supabase Realtime channel pada tabel `transactions` & `payment_confirmations` dengan Expo Push Notifications saat ada pembayaran baru masuk.
