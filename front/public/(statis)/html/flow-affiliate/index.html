TAHAP 1 DARI 6

Pendaftaran Akun & Pembuatan Link Referral

Aktor: Afiliator & Sistem Supabase

Afiliator yang terdaftar di Panggung Kreator memiliki kode referral unik yang digenerate otomatis oleh sistem saat pendaftaran profil atau membership. Link referral ini berisi parameter query pengenal yang dapat dilacak secara akurat.

Instruksi Langkah Demi Langkah
  1. Afiliator masuk ke platform melalui halaman login di https://panggungkreator.web.id/login.
  2. Buka halaman Profil Saya pada menu samping atau url /myprofile.
  3. Lihat kartu informasi Afiliasi & Referral pada bilah sisi profil.
  4. Salin Kode Afiliasi (contoh: PK-RIZAL-8921) atau Salin Link Referral Lengkap.
  5. Pastikan format link referral valid mengarah ke landing page akademi.

Aktor: Afiliator

Afiliator menyebarkan tautan referral dan kode kupon ke audiens target melalui berbagai kanal komunikasi digital, seperti media sosial, bio profil, konten edukasi, artikel blog, atau pesan broadcast komunitas.

Instruksi Langkah Demi Langkah

  2. Cantumkan link referral lengkap pada bio Instagram, TikTok, YouTube deskripsi, atau pesan langsung.

TAHAP 3 DARI 6

Klik Tautan & Tracking Kunjungan Calon Member

Aktor: Calon Member & Sistem Web

Saat calon member mengeklik link referral yang dibagikan, sistem secara otomatis membaca parameter query referral dari URL dan menyimpannya di memori sesi peramban agar tidak hilang saat pengguna menjelajahi halaman platform.

Instruksi Langkah Demi Langkah
  1. Calon member mengeklik link promosi dari media sosial atau pesan chat.
  2. Browser membuka halaman pendaftaran /akademi?ref=PK-RIZAL-8921.
  3. Komponen aplikasi membaca parameter ref dan memvalidasi keberadaan kode di database.
  4. Kode referral tersimpan pada session storage atau state form checkout.
  5. Calon member meninjau rincian paket akademi dan mengklik tombol Daftar Sekarang.

TAHAP 4 DARI 6

Registrasi Data Diri & Checkout Pembayaran

Aktor: Calon Member

Calon member mengisi formulir registrasi akun baru di halaman checkout. Sistem mengaitkan ID member afiliator ke data pendaftaran baru dan menghitung nominal transfer dengan kode unik 3 digit acak untuk verifikasi otomatis.

Instruksi Langkah Demi Langkah
  1. Calon member berada di halaman /akademi/checkout.
  2. Mengisi data diri: Nama Lengkap, Nomor WhatsApp aktif, Alamat Email, dan Password pilihan.
  3. Memastikan kolom Kode Referral terisi kode afiliator (auto-fill dari link).
  4. Sistem membuat data member baru dengan status pembayaran pending dan referred_by mengarah ke afiliator.
  5. Calon member melihat nominal total (misal: Rp 49.382) beserta QRIS resmi Panggung Kreator.
  6. Calon member melakukan transfer tepat sesuai nominal hingga 3 digit terakhir.

TAHAP 5 DARI 6

Verifikasi Pembayaran & Penerbitan Reward Komisi

Aktor: Admin & Sistem Server Action

Admin memverifikasi bukti transfer pembayaran di dasbor admin. Saat admin menyetujui transaksi, sistem secara otomatis mengeksekusi tiga tindakan sekaligus: aktivasi akun pembeli, penambahan saldo komisi afiliator, dan pengiriman notifikasi email ke kedua pihak.

Instruksi Langkah Demi Langkah
  1. Admin membuka dasbor manajemen transaksi di /admin/payment atau /admin/referral.
  2. Admin mencocokkan mutasi bank / QRIS dengan bukti transfer yang dikirim pembeli.
  3. Admin mengklik tombol Konfirmasi Pembayaran pada baris transaksi terkait.
  4. Sistem mengubah status member baru menjadi paid dan tier menjadi membership.
  5. Sistem mendeteksi kolom referred_by pada member baru dan mengambil setting komisi (contoh: Rp 10.000 per referral).
  6. Saldo commission_balance milik afiliator bertambah secara instan.
  7. Sistem mencatat transaksi kredit pada tabel commission_ledger sebagai bukti pembukuan.
  8. Sistem mengirim email kredensial akun ke pembeli dan email notifikasi komisi masuk ke afiliator.

TAHAP 6 DARI 6

Monitoring Saldo & Pencairan Komisi (Withdrawal)

Aktor: Afiliator & Admin Keuangan

Afiliator dapat memantau riwayat reward komisi dan mengajukan pencairan saldo (payout) ke nomor rekening bank atau dompet digital yang terdaftar. Admin keuangan memproses transfer dan memperbarui buku besar sistem.

Instruksi Langkah Demi Langkah
  1. Afiliator memeriksa akumulasi saldo komisi di dasbor profil /myprofile atau tab Afiliasi.
  2. Jika saldo telah mencapai batas minimum penarikan (misal: Rp 50.000), klik tombol Ajukan Penarikan Dana.
  3. Mengisi informasi rekening tujuan: Nama Bank, Nomor Rekening, dan Nama Pemilik Rekening.
  4. Sistem mencatat permohonan penarikan dana dengan status pending approval.
  5. Admin keuangan meninjau permintaan, melakukan transfer dana melalui perbankan resmi Panggung Kreator.
  6. Admin mengunggah bukti transfer dan menandai permohonan selesai (approved/completed).
  7. Saldo commission_balance terpotong dan transaksi debit tercatat rapi di commission_ledger.
TAMPILAN VISUAL MODAL PENCAIRAN KOMISI: /myprofile
Saldo Tersedia: Rp 150.000
Nominal Penarikan: Rp 150.000
Bank Tujuan: BCA - 8820192811 a.n Rizal Pratama

Logika Data & Pembukuan Finansial
Tabel Ledger:
INSERT INTO commission_ledger (member_id, type='debit', amount=150000, source='payout_withdrawal')
Update Saldo:
UPDATE members SET commission_balance = commission_balance - 150000 WHERE id=memberId
Audit Trail:
Pencatatan created_by, timestamps, balance_after, dan catatan nomor transfer.
