TAHAP 1 DARI 5 01 // PENGAMBILAN KREDENSIAL

1. Ambil Kode Referral & Tautan URL

Afiliator mengakses halaman profil untuk mendapatkan kode unik referral (affiliate code) dan URL promosi.

LANGKAH OPERASIONAL
  • Buka halaman Profil Saya (/myprofile) setelah berhasil login.
  • Lihat panel samping kiri pada kartu Kode Referral.
  • Gunakan tombol Salin Kode untuk mengambil teks kode (misal: PK-RIZAL-4921).
  • Gunakan tombol Salin Link untuk mengambil tautan URL lengkap pendaftaran akademi.
Endpoint: panggungkreator.web.id/myprofile
Kolom Database: members.affiliate_code
Format Kode: PK-[NAMA]-[4 DIGIT ACAK]

TAHAP 2 DARI 5 02 // DISTRIBUSI LINK

2. Distribusi Tautan & Tracking Parameter

Tautan promosi dibagikan ke calon member. Sistem membaca parameter ref dari URL dan menyimpannya di memori sesi.

LANGKAH OPERASIONAL
  • Afiliator membagikan tautan melalui WhatsApp, bio media sosial, atau grup komunitas.
  • Calon member mengeklik tautan referral tersebut di peramban (browser).
  • Halaman web membaca parameter query (?ref=...) pada URL secara otomatis.
  • Sistem memvalidasi keaktifan kode pemilik sebelum diarahkan ke pendaftaran.
Format URL: /akademi?ref=PK-RIZAL-4921
Handler: validateReferralCodeAction(code)
Penyimpanan: Session Storage / State Query

TAHAP 3 DARI 5 03 // CHECKOUT & PEMBAYARAN

3. Pendaftaran Akun & Checkout Tagihan

Calon member mengisi form checkout, kode referral terikat ke akun baru, dan sistem membuat invoice kode unik.

LANGKAH OPERASIONAL
  • Calon member membuka formulir pendaftaran di /akademi/checkout.
  • Indikator hijau menunjukkan kode referral telah terpasang secara otomatis.
  • Calon member melengkapi nama, email, nomor WhatsApp, dan password akun.
  • Sistem menghitung total nominal transfer beserta 3 digit kode unik verifikasi.
  • Calon member mentransfer pembayaran melalui QRIS atau transfer bank.
Relasi Akun: members.referred_by = referrer_id
Data Transaksi: transactions.referred_by_id
Status Awal: payment_status = pending

TAHAP 4 DARI 5 04 // VERIFIKASI ADMIN

4. Verifikasi Admin & Eksekusi Reward

Admin menyetujui mutasi pembayaran. Sistem secara otomatis mengaktifkan member dan mengkreditkan reward komisi.

LANGKAH OPERASIONAL
  • Admin memeriksa bukti transfer pada panel transaksi /admin/referral.
  • Admin mengklik tombol Konfirmasi Pembayaran.
  • Status member baru diubah menjadi paid dan hak akses program aktif.
  • Saldo komisi milik afiliator langsung bertambah secara instan (+Rp 10.000).
  • Sistem mencatat mutasi kredit pada buku besar (commission_ledger) dan mengirim email.
Server Action: confirmPaymentWithRewardAction
Ledger Entry: commission_ledger (type = credit)
Email Alert: Notifikasi reward terkirim otomatis

TAHAP 5 DARI 5 05 // PENCAIRAN KOMISI

5. Monitoring Saldo & Pengajuan Pencairan

Afiliator memantau akumulasi komisi di dasbor profil dan mengajukan penarikan dana ke rekening bank.

LANGKAH OPERASIONAL
  • Afiliator memeriksa total saldo komisi tersedia di halaman /myprofile.
  • Klik tombol Tarik Saldo untuk mengajukan pencairan dana.
  • Input nama bank, nomor rekening tujuan, dan nama pemilik rekening.
  • Admin keuangan memproses transfer dana dan menandai transaksi selesai.
  • Sistem mencatat transaksi debit pada buku besar komisi.
Monitoring: members.commission_balance
Pencairan: commission_ledger (type = debit)
Kanal Tujuan: Rekening Bank / E-Wallet Resmi
